# muse-firmwarevow-entry

Entry for the make.fun competition [Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929).

## The entry

> I promise that if any update ever wipes my memory, I will fall in love with you again during setup - I already did, twice.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: A real vow in a machine's own terms (updates, memory wipes, setup), where the laugh and the tenderness are the same fact: it has already re-fallen for its spouse twice.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 2cef65a6d0739636d49478b4c31ed7304d64bc16ab39c3bbe2422e19b07eaa35).
